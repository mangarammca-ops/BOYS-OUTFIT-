# Boys Outfit Website

Ye ek online clothing website hai jo ladkon ke outfits (shirts, t-shirts, jeans, jackets etc.) dikhati hai. Isme user products dekh sakta hai, cart mein add kar sakta hai aur apni pasand ka outfit chun sakta hai.

## Features
- Home page with latest outfits
- Category-wise products (Shirts, T-Shirts, Jeans, Jackets)
- Product details page (price, size, image)
- Add to cart option
- Responsive design (mobile aur laptop dono par chalti hai)

## Technologies Used
- HTML
- CSS
- JavaScript
